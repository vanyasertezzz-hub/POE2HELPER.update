# Как получить бесплатные API-ключи для POE2 Helper

> **Не присылай ключи в чат** (ни мне, ни кому-либо). Всё, что отправлено в чат, сохраняется в истории сессии,
> и удалить оттуда ключ уже нельзя. Вставляй ключи **только в саму тулу**:
> **Настройки → ИИ и API → Ключи API → Сохранить.**
> Тула хранит их зашифрованными (Windows DPAPI, файл `data\secrets.bin`): расшифровать их может только твоя учётная
> запись Windows на этом ПК. В `.env`, логах, кэше и интерфейсе ключей нет: в интерфейсе виден только хвост `••••••a1b2`.

Рядом с каждым ключом тула показывает **срок действия** и **остаток квоты**. Если у провайдера несколько аккаунтов,
можно вставить несколько ключей через запятую: лимиты сложатся, и тула будет их чередовать.

**Минимальный набор (5 минут): Groq + Google Gemini.** Для запаса квоты без карты: Mistral, SambaNova, GitHub Models,
OpenRouter, Hugging Face. **Если сервис просит привязать карту — пропусти его**: тула работает и без него, роутер
просто распределит нагрузку по остальным.

Лимиты ниже — примерные бесплатные значения; провайдеры их периодически меняют. Тула сама читает реальные остатки
там, где API их сообщает.

---

## 1. Groq — быстрый чат  ·  поле `GROQ_API_KEY`
1. Открой https://console.groq.com и войди (Google или GitHub).
2. Слева **API Keys** → **Create API Key** → придумай имя (например `poe2helper`) → **Submit**.
3. Скопируй ключ (`gsk_…`). Он показывается **один раз**.
- Бесплатно: около 1000 запросов в день на большие модели, очень высокая скорость. Карта не нужна.
- Срок: бессрочный, пока не удалишь.

## 2. Google Gemini — отчёты, аудит, скриншоты  ·  поле `GEMINI_API_KEY`
1. Открой https://aistudio.google.com/apikey и войди в Google-аккаунт.
2. **Create API key** → выбери или создай проект → скопируй ключ (`AIza…`).
- Один ключ работает и для Gemini Flash (роль «big»), и для Flash-Lite (роль «chat»).
- Бесплатно: огромный контекст, суточные лимиты на запросы. Карта не нужна.
- Срок: бессрочный.

## 3. Cerebras — НЕОБЯЗАТЕЛЬНО (может требовать карту)  ·  поле `CEREBRAS_API_KEY`
> Если при регистрации просят привязать карту — **пропусти Cerebras**, он не нужен.

1. Открой https://cloud.cerebras.ai и зарегистрируйся.
2. Появится окно **«Add credits to get started»**: выбери нижний вариант **Limited Credits** (бесплатные $5, карта не
   нужна) → **Continue**. Вариант **Pay as You Go $10** платный, его **не выбирай**.
3. **API Keys** → **Generate API Key** → скопируй (`csk-…`).
- Бесплатно: стартовые кредиты $5 с пониженными лимитами. Когда кредиты кончатся, тула просто перестанет выбирать
  Cerebras и перейдёт на другие модели.
- Срок ключа: бессрочный (кредиты могут иметь свой срок — смотри в кабинете, при желании укажи дату через ✎).

## 4. Mistral — длинные отчёты  ·  поле `MISTRAL_API_KEY`
1. Открой https://console.mistral.ai и зарегистрируйся.
2. **Billing / Plans** → выбери бесплатный план **Experiment** (нужно подтвердить номер телефона, карта не нужна).
3. **API Keys** → **Create new key** → скопируй.
- Бесплатно: большой месячный объём токенов, ограничение около 1 запроса в секунду.
- Срок: при создании можно задать дату окончания. Если задал — укажи её в туле кнопкой ✎ рядом с ключом.

## 5. SambaNova — чат  ·  поле `SAMBANOVA_API_KEY`
1. Открой https://cloud.sambanova.ai и зарегистрируйся.
2. **APIs** (или **API Keys**) → **Create API Key** → скопируй.
- Бесплатный тир с суточными лимитами.

## 6. NVIDIA NIM — запас  ·  поле `NVIDIA_API_KEY`
1. Открой https://build.nvidia.com и войди (аккаунт NVIDIA).
2. Открой любую модель (например Llama 3.3 70B) → **Get API Key** → **Generate Key** → скопируй (`nvapi-…`).
- Бесплатные кредиты на запросы. Если NVIDIA покажет дату окончания кредитов, укажи её в туле через ✎.

## 7. OpenRouter — запас (бесплатные модели `:free`)  ·  поле `OPENROUTER_API_KEY`
1. Открой https://openrouter.ai и войди.
2. Справа вверху меню → **Keys** → **Create Key** → можно задать лимит в $0 → скопируй (`sk-or-…`).
- Бесплатно: модели с пометкой `:free`, около 50 запросов в день (после пополнения на $10 — около 1000 в день).
- Тула показывает реальный остаток с API OpenRouter.

## 8. GitHub Models — запас, умеет картинки  ·  поле `GITHUB_TOKEN`
1. Открой https://github.com/settings/personal-access-tokens → **Generate new token** (Fine-grained).
2. Имя: `poe2helper`. **Expiration** — выбери срок (тула покажет, сколько дней осталось).
3. **Repository access: Public repositories (read-only)**. В **Permissions → Account** включи **Models: Read-only**
   (если такого пункта нет, оставь права по умолчанию).
4. **Generate token** → скопируй (`github_pat_…`).
- Бесплатно: около 150 запросов в день на модели уровня GPT-4.1-mini.

## 9. Cohere — запас  ·  поле `COHERE_API_KEY`
1. Открой https://dashboard.cohere.com и зарегистрируйся.
2. **API Keys** → скопируй **Trial key**.
- Пробный ключ: около 1000 запросов в месяц. Только для некоммерческого использования.

## 10. Hugging Face — запас  ·  поле `HF_TOKEN`
1. Открой https://huggingface.co/settings/tokens → **Create new token**.
2. Тип **Fine-grained** → включи **Make calls to Inference Providers** → **Create** → скопируй (`hf_…`).
- Небольшие ежемесячные бесплатные кредиты.

## 11. Cloudflare Workers AI — запас  ·  поля `CF_API_TOKEN` и `CF_ACCOUNT_ID`
1. Открой https://dash.cloudflare.com и зарегистрируйся.
2. **Account ID**: на главной странице аккаунта справа (или в адресной строке) — скопируй в поле `CF_ACCOUNT_ID`.
3. Значок профиля → **My Profile → API Tokens → Create Token** → шаблон **Workers AI** → **Continue → Create Token**.
4. Скопируй токен в `CF_API_TOKEN`. Срок действия (если задан) тула прочитает сама.
- Бесплатно: 10 000 «нейронов» в день.

## 12. xAI Grok — необязательно (платный)  ·  поле `XAI_API_KEY`
https://console.x.ai → **API Keys**. Бесплатной квоты обычно нет, поэтому в цепочках он стоит в конце.

## 13. Ollama (уже установлена) — ключ не нужен
Работает локально и без лимитов: `qwen3:4b-instruct` для фоновой работы, `qwen3-vl:8b` для скриншотов. Это
гарантированный запасной вариант: даже при нулевых облачных квотах тула продолжает отвечать.

## Path of Exile (по желанию)
- **Имя аккаунта** `POE_ACCOUNT` (вида `Name#1234`) — для чтения персонажей из публичного профиля.
  На pathofexile.com: **My Account → Privacy Settings** → разреши показ вкладки «Characters».
- **POESESSID** — cookie сайта pathofexile.com. Даёт доступ к закрытому профилю, но это **полный доступ к аккаунту**.
  Используй, только если очень нужно, вставляй только в тулу (она его тоже шифрует) и смени пароль,
  если подозреваешь утечку. Без него всё основное работает.

## Если ключ утёк
Зайди на сайт провайдера → раздел ключей → **Delete/Revoke** этот ключ → создай новый → вставь в тулу.
